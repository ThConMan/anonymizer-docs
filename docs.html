Documentation

Everything Anonymizer does, in plain English. Built for Paper / Minecraft 26.x, Java 21+.

Overview

Anonymizer makes invisibility actually mean invisibility. On competitive servers, an invisibility potion hides your body but not your name — kill someone and chat, the death message, the tab list, and your floating nametag all announce exactly who you are. Anonymizer closes all of it: the name scrambles to a flickering &k run wherever it would be printed, the floating nametag is hidden outright, the tab entry loses the name and the skin on the head, and the rank prefix goes with it — so a stealth kill leaves nothing to identify.

Anonymizer never reveals more than it has to. The default tab mode keeps players listed but strips their skin to a generic head — the real skin is never sent to other clients while a player is hidden.

Install

  1. Download Anonymizer-x.y.z.jar.
  2. Drop it in your server's plugins/ folder (remove any older Anonymizer jar).
  3. Restart the server.
  4. Adjust plugins/Anonymizer/config.yml and run /anonymizer reload. That's it.

Optional soft-depends (all auto-detected by reflection, no hard dependencies): EssentialsX, CMI, VentureChat.

The trigger

A player is anonymized whenever they carry the Invisibility potion effect. That's the only requirement by default.

For servers that want true ghosts only, there are two extra requirements you can add — trigger.require-no-armor (all four armor slots empty) and trigger.require-empty-hands (main and off hand empty). Turn both on and a player is anonymized only when they're invisible and wearing no armor and holding nothing. Both are off by default: armor and held items still render and give away a player's position, but the point of the plugin is hiding their name.

Setting trigger.invisibility-potion to false widens the trigger instead — any invisible player counts, including invisibility granted by another plugin. Anyone with the anonymizer.bypass permission is never anonymized.

The moment the Invisibility effect ends, the player's real name returns everywhere automatically.

What gets redacted

The redacted name

A hidden player's name becomes a flickering bold-white block using Minecraft's &k obfuscation. Configure redacted-name.flicker, redacted-name.glyph, and redacted-name.length, or disable the flicker for a clean, solid bar.

Chat

The sender's name is redacted in chat. Anonymizer listens at MONITOR priority (last) and replaces by content, so the redaction survives other chat plugins' formatting — including gradient titles from plugins like DragonReign.

Death messages

If a hidden player is the killer or the victim, their real name is scrubbed out of the broadcast death message before it reaches the server.

Tab list

tab-mode: hide-skin (default) keeps the player listed but strips their skin so the head shows a generic default. Other modes: name-only (redact the name only), remove (drop them from the list entirely), and off.

Nametag

The floating in-world username is hidden through a scoreboard team, so a hidden player's name can't be read through walls or across distance.

Plugin name sources

Nicknames from EssentialsX, CMI, and VentureChat are redacted too — see Plugin hooks.

Rank prefix

A rank bracket outs a player as surely as a name does. The LuckPerms prefix is blanked while hidden, and CMI's chat module — which bakes the bracket in as literal text — is handled by the cmi-chat-group switch.

Staff menu

Run /anonymizer in game to open the settings menu. Every option in config.yml is in it, and each click writes straight back to the file and takes effect immediately — no reload, no restart, no editing YAML.

ControlHow it works
TogglesClick to flip. The item name and its lore both show the current state.
NumbersLeft-click +1, right-click -1. Hold shift for bigger steps. Values are clamped to a sane range.
ModesLeft-click for the next value, right-click for the previous. All choices are listed in the lore with the active one marked.

Three of the items are live panels rather than settings: a preview of the hidden name exactly as the server renders it, Detected hooks listing the name systems Anonymizer actually found on this server, and Hidden right now — the staff-only roster of who is anonymized, by real name.

The master switch

The top item in the menu (also /anonymizer toggle, and enabled in the config) turns anonymization off for the entire server. Everyone currently hidden is restored the instant it flips, and turning it back on re-hides them just as fast — nothing is lost either way. It's saved to the config, so it survives a restart.

Useful for events where staff want names visible, or to rule Anonymizer out in one click while debugging another plugin.

Config

The whole config.yml is commented in plain language, and every setting in it is also editable from the in-game menu — you only need to open the file if you prefer to.

enabled: true            # master switch — false anonymizes nobody, server-wide

redacted-name:
  length: 10             # how many characters wide the hidden name is
  flicker: true          # animate it with Minecraft's &k obfuscation
  bold: false            # render it bold
  glyph: "#"             # the character it's built from (with flicker on you
                         # only ever see the scramble, not this character)

trigger:                 # what makes a player count as hidden
  invisibility-potion: true    # require the Invisibility effect
  require-no-armor: false      # also require all 4 armor slots empty
  require-empty-hands: false   # also require main + off hand empty

redact:                  # where the redaction is applied
  display-name: true     # the main lever — covers vanilla chat, vanilla death
                         # messages and most chat plugins for free
  death-messages: true   # safety net: scrub the real name from death messages
  chat-plugins: true     # redact plugins that keep their OWN name (EssentialsX,
                         # CMI, VentureChat, the LuckPerms prefix, TAB)
  nametag: true          # hide the floating in-world username
  tab-mode: hide-skin    # hide-skin | name-only | remove | off
  cmi-chat-group: 50     # CMI rank-bracket fix (0 = off)
  hidden-skin:
    texture: ''          # optional base64 skin to show instead of the default head
    signature: ''

check-interval-ticks: 10 # safety-net re-check (events already update instantly)
debug: false
Changes made in the GUI are written back into this file and take effect immediately. Your comments survive that write — only the neat column alignment of the inline ones is re-flowed.

Plugin hooks

All hooks are auto-detected through reflection, so Anonymizer has no hard dependencies and runs fine without any of them.

PluginWhat Anonymizer does
EssentialsXRedacts the hidden player's nickname in /list, /seen, /near, and /whois.
CMIRedacts the hidden player's CMI nickname.
VentureChatRedacts the sender's name in VentureChat channels.
ChatControl / DeluxeChat / CarbonChatDetected and logged with a short config tip so you can wire the redaction into their formats.
Some chat plugins build their messages entirely in their own pipeline. For ChatControl, DeluxeChat, and CarbonChat, Anonymizer logs a one-line tip on startup explaining how to slot the redacted name into their format strings.

FAQ

Does it work without any chat plugin?

Yes. The chat, death message, tab, and nametag redactions are all native — no other plugin required.

Can someone still see the real skin in tab?

No. In the default hide-skin mode the real skin is never sent while a player is hidden; the head shows a generic default.

What if another plugin re-adds the name?

Anonymizer's chat listener runs last (MONITOR) and replaces by content, so it overrides formatting added earlier in the chain.

How do I exempt staff?

Grant anonymizer.bypass. Those players are never anonymized, invisible or not.
